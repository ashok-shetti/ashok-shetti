## 🚀 Featured Projects

### 🐞 [BugTrace AI](https://github.com/ashok-shetti/bugtrace-ai)

AI-powered bug resolution assistant that uses historical GitHub issues and maintainer fixes to help diagnose errors, identify likely root causes, and suggest fixes.

- **Architecture:** Hybrid RAG using vector search, PostgreSQL full-text search, Reciprocal Rank Fusion (RRF), and Google Gemini structured outputs
- **Stack:** FastAPI · PostgreSQL · pgvector · Sentence Transformers · Gemini API

---

### 🍽️ [DineMatch](https://github.com/ashok-shetti/dinematch)

Restaurant discovery application that lets users search and filter restaurants by cuisine, location, budget, rating, and restaurant name, with a separate content-based similarity recommender.

- **Architecture:** FastAPI-based filtering and search with TF-IDF and cosine similarity for restaurant similarity
- **Dataset:** 51,717 raw records reduced to 12,787 cleaned records
- **Stack:** Python · FastAPI · Pandas · Scikit-learn · TF-IDF

---

### 🛡️ [FraudWatch](https://github.com/ashok-shetti/fraudwatch)

Fraud detection system built on the IEEE-CIS dataset, comparing LightGBM and XGBoost with stratified 5-fold cross-validation and a Streamlit prediction dashboard.

- **Result:** XGBoost achieved 0.9694 mean OOF ROC-AUC across 5 folds
- **Stack:** Python · XGBoost · LightGBM · Scikit-learn · Streamlit

---

### 🌐 [Network Anomaly Detection System](https://github.com/ashok-shetti/network-anomaly-detection-system)

Unsupervised network anomaly detection system that compares Isolation Forest and Local Outlier Factor (LOF), assigns anomaly severity, and presents results through a Flask dashboard.

- **Result:** LOF achieved 0.6343 F1, compared with 0.2145 for Isolation Forest on the UNSW-NB15 test set
- **Stack:** Python · Scikit-learn · Flask · SQLite · Plotly
